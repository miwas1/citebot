# Third-party content

The MIT License in the repository root applies to CiteBot's original source code and project documentation. It does not automatically relicense downloaded papers, abstracts, metadata, or other third-party content under `data/`.

The bundled research records retain their source URLs and publisher metadata. Before redistributing a build that includes them, verify the applicable license for each work and remove records for which redistribution is not permitted. New corpus downloads should be treated the same way.
